# 🏢 ربات تلگرام مدیریت ساختمان (Telegram Building Manager)

این یک ربات تلگرام پیشرفته و متن‌باز برای مدیریت شارژ، هزینه‌ها و ساکنین ساختمان‌های مسکونی است که با زبان پایتون نوشته شده است.

این پروژه با استفاده از کتابخانه `python-telegram-bot` و دیتابیس `SQLAlchemy` طراحی شده و برای مدیران ساختمان‌ها ابزاری کارآمد جهت شفاف‌سازی مالی و ارتباط با ساکنین فراهم می‌کند.

## ✨ ویژگی‌ها (Features)

### 👮‍♂️ پنل مدیریت (Admin Panel)
- **مدیریت واحدها:** افزودن، ویرایش و حذف ساکنین (نام، واحد، شماره تماس).
- **مدیریت مالی:**
  - تعریف شارژ ماهیانه خودکار (Job Queue).
  - ثبت هزینه‌های ساختمان همراه با توضیحات و **عکس فاکتور**.
  - تایید یا رد واریزی‌های ارسالی توسط ساکنین.
  - مشاهده موجودی لحظه‌ای صندوق ساختمان.
- **گزارش‌گیری:** دریافت فایل اکسل (Excel) کامل از وضعیت بدهی‌ها، واریزی‌ها و هزینه‌ها.
- **تنظیمات:** تغییر شماره کارت، مبلغ شارژ و روز سررسید.
- **ارسال پیام:** امکان ارسال پیام همگانی، پیام به بدهکاران یا پیام به یک واحد خاص.

### 👤 پنل ساکنین (Resident Panel)
- **مشاهده وضعیت:** دیدن میزان بدهی یا بستانکاری و شماره واحد.
- **تاریخچه تراکنش‌ها:** مشاهده لیست پرداختی‌های قبلی و وضعیت تایید آن‌ها.
- **ثبت پرداخت:** امکان ارسال فیش واریزی (کارت به کارت) برای مدیر.
- **شفافیت مالی:** مشاهده وضعیت صندوق ساختمان و آخرین هزینه‌های انجام شده (همراه با عکس فاکتورها).

## 🛠 پیش‌نیازها

- Python 3.8 یا بالاتر
- یک توکن ربات از [BotFather@](https://t.me/BotFather)

## 🚀 نصب و راه‌اندازی

۱. **کلون کردن مخزن:**
git clone https://github.com/YOUR_USERNAME/telegram-building-bot.git
cd telegram-building-bot



۲. **ساخت محیط مجازی (Virtual Environment):**
python -m venv .venv

در ویندوز:
.venv\Scripts\activate

در لینوکس/مک:
source .venv/bin/activate



۳. **نصب وابستگی‌ها:**
pip install -r requirements.txt



۴. **تنظیمات محیطی:**
- فایل `.env.example` را به `.env` تغییر نام دهید.
- فایل `.env` را باز کنید و توکن ربات خود را وارد کنید:
  ```
  BOT_TOKEN=your_token_here
  ```

۵. **اجرای ربات:**
python main.py



---

## 💡 نحوه استفاده (First Run)

1. پس از اولین اجرای ربات، دستور `/start` را بزنید.
2. ربات از شما می‌پرسد: **"مدیر هستم"** یا **"ساکن هستم"**.
3. **اولین نفری** که گزینه "مدیر هستم" را انتخاب کند، به عنوان مدیر کل سیستم ثبت می‌شود و دسترسی پنل مدیریت را دریافت می‌کند.
4. سایر کاربران باید گزینه "ساکن هستم" را انتخاب کنند و آیدی عددی نمایش داده شده را برای مدیر بفرستند تا مدیر آن‌ها را در سیستم ثبت کند.

## 📂 ساختار پروژه

telegram-building-bot/
├── database/ # مدل‌ها و تنظیمات دیتابیس (SQLite)
├── handlers/ # منطق دکمه‌ها و دستورات (Admin, Resident, Common)
├── utils/ # ابزارهای کمکی (تاریخ شمسی، کیبوردها)
├── media/ # محل ذخیره عکس فیش‌ها و فاکتورها (تولید خودکار)
├── jobs.py # کارهای زمان‌بندی شده (شارژ خودکار)
├── main.py # فایل اصلی اجرا
├── config.py # تنظیمات خواندن توکن
└── requirements.txt # لیست کتابخانه‌ها

## 🐳 اجرا با داکر (Docker)

برای اجرای آسان و مطمئن ربات روی سرور یا سیستم شخصی، می‌توانید از داکر استفاده کنید.

### پیش‌نیازها
- نصب بودن Docker و Docker Compose.

### مراحل اجرا

۱. **ساخت فایل تنظیمات:**
   فایل `.env.example` را به `.env` تغییر نام داده و توکن ربات را وارد کنید.

۲. **اجرا:**
   در پوشه اصلی پروژه دستور زیر را بزنید:
docker-compose up -d


(سوییچ `-d` باعث می‌شود ربات در پس‌زمینه اجرا شود).

۳. **مشاهده لاگ‌ها:**
برای دیدن وضعیت ربات و خطاها:
docker-compose logs -f



۴. **توقف ربات:**
docker-compose down

۵. **آپدیت ربات:**
اگر تغییری در کد دادید، برای اعمال تغییرات در داکر:
docker-compose up -d --build
